# Pi School Git Practice

A small public repository for practicing Git and GitHub.

## What I am learning

- Create a local Git repository.
- Stage files and save a commit.
- Review changes with `git diff` before committing.
- Push commits to a public GitHub repository.

## Useful commands

- `git status`: inspect the working tree and staging area.
- `git add README.md`: stage the selected file.
- `git commit -m "message"`: save the staged changes.
- `git diff`: review unstaged changes.
